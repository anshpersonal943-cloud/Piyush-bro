## 📊 API Documentation

### Endpoints
```
GET  /                    # Home page
GET  /memories            # Get all memories
POST /upload              # Upload new memory
PUT  /memory/:id          # Edit memory
DELETE /memory/:id        # Delete memory
```

### Memory Data Format
```json
{
  "id": 1691234567890,
  "title": "Memory Title",
  "message": "Memory description",
  "image": "/uploads/filename.jpg",
  "createdAt": "2024-08-05T10:30:00.000Z"
}
```
